# Project Context - Recruitment Tracker Automation

## Summary

Ahmad helped an Upwork client build an automated recruitment tracker and recruitment operations app using Coda.io.

The project focused on designing a structured recruitment database, building a dashboard for pipeline tracking, and automating parts of the hiring workflow so the client could manage recruitment more smoothly without developing a separate custom application.

## Problem

The client needed a better way to manage recruitment pipeline tracking.

Likely pain points:

- Candidate data needed to be organized in one structured system.
- Recruitment status and pipeline movement needed clearer visibility.
- Manual candidate follow-up could slow the process.
- Qualified candidates needed a smoother way to receive interview booking instructions.
- The client wanted a practical solution without building a separate software application.

## Solution

Ahmad designed and built a recruitment tracker app in Coda.io.

The solution included:

- Recruitment tables.
- Relational table design.
- Candidate pipeline tracking.
- Recruitment dashboard.
- Candidate qualification logic.
- Automated email flow for eligible candidates.
- Cal.com integration for self-service interview booking.

## Workflow

High-level workflow:

1. Candidate applies or is added to the recruitment tracker.
2. Candidate data is stored in structured Coda.io tables.
3. Candidate criteria are reviewed or evaluated through the tracker.
4. Candidates who match the criteria are moved into the appropriate pipeline status.
5. The system automatically sends email instructions to qualified candidates.
6. Qualified candidates receive a Cal.com booking link.
7. Candidates independently book their interview schedule.
8. Recruitment team tracks candidate status and progress from the Coda.io dashboard.
