# Semakin Banyak Data Belum Tentu Semakin Paham

## Core Idea

Data yang terlalu banyak tanpa pertanyaan yang jelas bisa membuat tim terlihat lengkap secara informasi, tapi tetap bingung mengambil keputusan.

## Hook Options

- Semakin banyak data belum tentu semakin paham.
- Kadang masalahnya bukan kurang data, tapi kurang pertanyaan yang jelas.
- Dashboard penuh angka tidak otomatis membuat bisnis lebih mengerti.

## Draft Threads Post

Semakin banyak data belum tentu semakin paham.

Kadang tim sudah punya banyak angka.

Ada dashboard.
Ada spreadsheet.
Ada report mingguan.
Ada export dari sistem.

Tapi saat harus mengambil keputusan, tetap bingung.

Kenapa?

Karena data tanpa pertanyaan yang jelas hanya menjadi kumpulan angka.

Sebelum mengumpulkan data, menurut saya perlu tanya:

Apa yang ingin kita pahami?
Keputusan apa yang mau dibantu?
Kalau angkanya naik, kita akan apa?
Kalau angkanya turun, kita akan apa?

Kalau pertanyaan ini belum jelas, menambah data sering hanya menambah pekerjaan.

Bukan menambah pemahaman.

## Angle Note

Bisa dikaitkan ke pengalaman KPI dan dashboard, tapi jangan terlalu formal.

## Soft CTA

Kamu lebih sering melihat tim kekurangan data atau kebanyakan data tapi tetap bingung?
