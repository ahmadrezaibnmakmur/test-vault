# AnyFlo GTM Roadmap

## Target Market / ICP

Start with mid-size operational-heavy companies.

Company characteristics:

- Banyak proses approval.
- Banyak pekerjaan berulang.
- Masih banyak memakai Google Sheets, WhatsApp, dan email.
- Punya banyak cabang, tim lapangan, atau department.
- Butuh custom workflow tapi belum punya budget besar untuk custom software.

Priority segments:

- Operations Team
- HR Team
- Finance and Procurement
- Field Operations

Recommendation:

> Mulai dari Operations, HR, dan Procurement karena workflow mereka biasanya jelas, painful, dan mudah dihitung ROI-nya.

## GTM Phases

### Phase 1 - Founder-Led Sales

Target: validasi problem dan dapat 3-5 pilot customer.

Activities:

- Buat landing page sederhana.
- Buat demo 3 use case: purchase request approval, employee request workflow, field visit workflow.
- Reach out ke network pribadi.
- Tawarkan free workflow audit.
- Convert audit menjadi paid pilot.

Initial offer:

> Free Workflow Audit: kami bantu mapping proses kerja Anda dan tunjukkan bagian mana yang bisa didigitalisasi dengan AnyFlo.id.

### Phase 2 - Use Case-Based Selling

Jangan jual platform fleksibel terlalu awal. Jual use case spesifik.

Landing page examples:

- AnyFlo for Purchase Approval
- AnyFlo for Field Operations
- AnyFlo for HR Request
- AnyFlo for Internal Service Request

Reason:

> Buyer membeli solusi untuk masalah spesifik, bukan membeli fleksibilitas secara abstrak.

### Phase 3 - Template Marketplace

After customer validation, build templates:

- Purchase Request Template
- Reimbursement Template
- Field Visit Template
- Employee Onboarding Template
- Maintenance Request Template
- Recruitment Workflow Template

### Phase 4 - Partner Channel

Target partners:

- Digital transformation consultant
- HR consultant
- Small ERP consultant
- Operations consultant
- No-code/automation agency

## Pricing Strategy

Option A - Subscription + Setup Fee:

- Setup fee: Rp5 juta - Rp25 juta.
- Monthly subscription: Rp1 juta - Rp10 juta/bulan.

Option B - Use Case Package:

- Starter Workflow Package: 1 workflow, form, approval, basic dashboard, notification, monthly support.
- Growth Workflow Package: 3-5 workflows, role-based access, dashboard, integration, SLA support.
- Enterprise Workflow Package: multi-department, custom logic, integration, advanced reporting, dedicated support.

Recommended starting point:

> Use case package, because it is easier for customers to understand.

## 90-Day Roadmap

### Day 1-30 - Foundation

Outputs:

- Define ICP.
- Create positioning.
- Build landing page.
- Prepare 3 demo workflows.
- Create sales deck.
- Create workflow audit checklist.

Targets:

- 20 discovery calls.
- 5 workflow audits.
- 2 pilot customers.

### Day 31-60 - Validation

Outputs:

- Run pilot implementation.
- Collect feedback.
- Measure before-after impact.
- Build case study.
- Refine pricing.

Targets:

- 3-5 pilot customers.
- 1-2 paid customers.
- 1 case study.

### Day 61-90 - Repeatability

Outputs:

- Build templates.
- Create outbound script.
- Create partner proposal.
- Launch use-case landing pages.
- Publish weekly content.

Targets:

- 10 qualified leads/month.
- 3 sales opportunities/month.
- 1-3 new customers/month.

## Recommended First Offer

Free Workflow Audit for Operations Teams.

Description:

> Kami bantu mapping proses kerja manual Anda, menemukan bottleneck, dan memberikan rekomendasi workflow digital yang bisa dibuat di AnyFlo.id.

Why this is strong:

> Buyer mungkin belum sadar mereka butuh workflow app, tapi mereka sadar proses mereka berantakan.
