# AnyFlo Problem and Use Case Map

## Beachhead Use Cases

### Approval Workflow

Examples:

- Purchase request
- Reimbursement
- Leave request
- Budget approval
- Document approval

Why it is a strong starting use case:

> Almost every company has an approval problem.

Core pain:

- WhatsApp is fast at first but hard to trace.
- Approval without clear status makes operations work by assumption.
- Real approval is conditional: amount, department, role, exception, urgency, document completeness.

### Field Visit / Task Workflow

Examples:

- Visit schedule
- Check-in/check-out
- Photo report
- Task completion
- Supervisor approval

Core pain:

- Field operation depends on manual updates.
- Without tracking, supervisors lose visibility.
- Blind spots appear during complaints, audits, or missed work.

### Internal Request Management

Examples:

- IT request
- HR request
- GA request
- Asset request
- Maintenance request

Core pain:

- Requests scattered across WhatsApp, email, private chats, and verbal requests.
- No single place for PIC, status, SLA, or supporting documents.
- The person who follows up most aggressively gets processed faster.

## Problem Patterns

### Software Forces the Process

The company is forced to fit rigid app logic instead of using software that follows its actual process.

### Spreadsheet Becomes Operational Debt

Spreadsheet is useful for exploration, but can become risky when workflows become repetitive, multi-role, approval-heavy, and operationally critical.

Common symptoms:

- Too many sheets.
- Too many file versions.
- Broken formulas.
- Manual data entry.
- Status not updated automatically.
- Unclear ownership.

### Dashboard Without Status Is Weak

Real-time visibility does not start from charts. It starts from consistent workflow status.

Example status:

- Submitted
- In Review
- Need Revision
- Approved
- Done

### Build vs Buy Gap

SaaS standard is fast but rigid. Custom software is flexible but expensive and slow. Spreadsheet + WhatsApp remains flexible but messy. AnyFlo.id aims to become the middle path.
