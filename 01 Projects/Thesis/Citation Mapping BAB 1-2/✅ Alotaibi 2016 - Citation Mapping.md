## Ringkasan Kekuatan Sitasi

Alotaibi (2016) kuat sebagai landasan definisi Software as a Service. Artikel ini menjelaskan SaaS sebagai model bisnis dan delivery model berbasis internet/cloud, di mana software di-host oleh vendor, pelanggan membayar subscription fee, vendor bertanggung jawab pada reliability, infrastructure, maintenance, security, user support, data backup, SLA, serta akses multi-tenant. Ini selaras dengan paragraf draft yang menjelaskan SaaS sebagai model berlangganan yang mengurangi beban infrastruktur IT lokal.

## Evidence Map Artikel

- PDF page 1: SaaS disebut sebagai delivery model dominan yang memanfaatkan cloud-computing infrastructure.
- PDF page 1: Artikel menyebut SaaS mengubah software menjadi service yang diberikan melalui internet.
- PDF page 2: Section 2.1 menjelaskan SaaS sebagai business model yang menggantikan on-premises software dengan web-based model.
- PDF page 2: Artikel menjelaskan tiga konsep pembeda SaaS: IT outsourcing, remote hosting, dan software licensing.
- PDF page 2: Artikel menyebut vendor bertanggung jawab pada infrastructure, software development, maintenance, security, user support, dan data backup.
- PDF page 2: Artikel menjelaskan software di-host vendor, pelanggan membayar subscription fee, dan akses dilakukan melalui multi-tenant architecture.
